# A04 · 折线图 (Line Chart)

- 分类：A 基础对比
- 用途：参数变化、训练过程
- 推荐方法：`ax.plot()`
- 优先级：—

## 规范提示
线宽 1.2–1.8 pt；多系列配合标记与线型区分

## 运行

```bash
python plot.py
```

依赖：`numpy`、`matplotlib`、`cycler`（见根目录 `requirements.txt`）。
样式加载自 `../../styles/paper.mplstyle`，在仓库根目录运行脚本即可。

| 文件 | 说明 |
