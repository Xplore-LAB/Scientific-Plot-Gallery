# A07 · 点图 (Dot Plot)

- 分类：A 基础对比
- 用途：多方法精确数值对比
- 推荐方法：`ax.scatter()`
- 优先级：—

## 规范提示
按数值排序；与误差棒图例区分清楚

## 运行

```bash
python plot.py
```

依赖：`numpy`、`matplotlib`、`cycler`（见根目录 `requirements.txt`）。
样式加载自 `../../styles/paper.mplstyle`，在仓库根目录运行脚本即可。

## 文件

| 文件 | 说明 |
|---|---|
| `plot.py` | 可运行 Python 模板 |
| `metadata.yaml` | 机器可读元数据 |
| `example.csv` | 示例数据结构（模拟数据） |
