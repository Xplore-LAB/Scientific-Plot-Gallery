# F07 · 流线图 (Streamline Plot)

- 分类：F 空间优化
- 用途：流体流动、状态场
- 推荐方法：`ax.streamplot()`
- 优先级：—

## 规范提示
注明起点密度与积分方向；避免流线过密

## 运行

```bash
python plot.py
```

依赖：`numpy`、`matplotlib`、`cycler`（见根目录 `requirements.txt`）。
样式加载自 `../../styles/paper.mplstyle`，在仓库根目录运行脚本即可。
